# Ferramenta: pytest
# Experiência: Tanto a escrita da função e os testes refletem a filosofia do Python de ser simples e legível com sua sintaxe dinâmica, sem muito boilerplate. Como ponto negativo, a falta de tipagem forte exige que o desenvolvedor confie menos na qualidade do própio código, e necessite de mais testes para pegar erros que poderiam ser descobertos com tipagem estática.
